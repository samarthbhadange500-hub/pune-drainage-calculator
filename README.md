# Pune Storm Drainage Calculator

Live Website: https://pune-drainage-calculator.streamlit.app

This tool calculates Peak Runoff (Q) using Rational Method (Q=CiA) and Required Pipe Diameter using Manning's Equation for Pune city.

Developed by Samarth Bhadange - Final Year Civil Capstone Project.

Features:
- Real-time calculation
- Pune rainfall data ready
- Pipe sizing as per IS standards

Tech: Python, Streamlit
